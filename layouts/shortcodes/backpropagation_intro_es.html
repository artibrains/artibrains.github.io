{{ if eq $lang "es" }}La Retropropagación (Backpropagation) es el motor de aprendizaje de las redes neuronales. Funciona como un sistema de "asignación de responsabilidades": cuando la red comete un error, este algoritmo calcula exactamente qué conexiones internas (pesos) contribuyeron al fallo y las ajusta en la dirección correcta. Este proceso iterativo de predicción, cálculo de error y ajuste es lo que permite a la red refinar su "conocimiento" y volverse cada vez más precisa.{{ else }}Backpropagation is the learning engine of neural networks. It works as a "responsibility assignment" system: when the network makes an error, this algorithm calculates exactly which internal connections (weights) contributed to the failure and adjusts them in the right direction. This iterative process of prediction, error calculation, and adjustment is what allows the network to refine its "knowledge" and become increasingly accurate.{{ end }}

{{ if eq $lang "es" }}¿Cómo aprende la red de sus errores?{{ else }}How does the network learn from its errors?{{ end }}

{{ if eq $lang "es" }}1. Predicción y Cálculo del Error{{ else }}1. Prediction and Error Calculation{{ end }}

{{ if eq $lang "es" }}La red procesa los datos de entrada (la imagen) a través de sus capas para generar una predicción. Luego, se compara esta predicción con el resultado correcto para cuantificar el error total.{{ else }}The network processes the input data (the image) through its layers to generate a prediction. Then, this prediction is compared with the correct result to quantify the total error.{{ end }}

{{ if eq $lang "es" }}2. Retropropagación de la "Culpa"{{ else }}2. Backpropagation of "Blame"{{ end }}

{{ if eq $lang "es" }}El error se propaga hacia atrás, desde la salida hasta la entrada, calculando cuánto "contribuyó" cada neurona y conexión al error final. A esta medida se le llama gradiente o delta (δ).{{ else }}The error propagates backward, from output to input, calculating how much each neuron and connection "contributed" to the final error. This measure is called gradient or delta (δ).{{ end }}

{{ if eq $lang "es" }}3. Ajuste de Pesos y Aprendizaje{{ else }}3. Weight Adjustment and Learning{{ end }}

{{ if eq $lang "es" }}Las conexiones (pesos) se ajustan ligeramente en función de su "culpa" para reducir el error en la próxima iteración. La tasa de aprendizaje (η) controla la magnitud de este ajuste.{{ else }}Connections (weights) are slightly adjusted based on their "blame" to reduce the error in the next iteration. The learning rate (η) controls the magnitude of this adjustment.{{ end }}

# Bloque de Código 2: Creando un conjunto de datos sintético y realista

# Estoy configurando una 'semilla aleatoria' aquí. Este es un paso crucial en la ingeniería de software
# para el aprendizaje automático. Asegura que nuestros números 'aleatorios' sean los mismos cada
# vez que ejecutamos este código, haciendo que nuestros resultados sean reproducibles.
np.random.seed(42)

# Simulemos datos para 50 días.

Paso 3: Definición de los componentes del modelo¶

Marta nos dio el plano, ahora definamos las piezas centrales en nuestro código:

  • La Hipótesis ($h(x)$): Esta es nuestra función de predicción. Para la regresión lineal, es solo la ecuación de una línea. La llamaré prediction(). $$prediction(x) = w * x + b$$ $w$ (peso) y $b$ (sesgo) son los parámetros que nuestro modelo aprenderá. Estos son los "mandos" que ajustaremos.
  • La Función de Coste ($J(w, b$)): Esto nos dice cómo de "equivocadas" están las predicciones de nuestro modelo. Cuanto menor, mejor. Usaremos el Error Cuadrático Medio (MSE), una elección bastante estándar. $$cost = averageOf( (prediction - actualvalue)^2 )$$
  • Descenso del Gradiente: Este es el proceso de aprendizaje en sí. Ajusta automáticamente $w$ y $b$ para minimizar el coste. Descubre la "pendiente" de la función de coste y da pasos cuesta abajo.

Paso 4: Implementación del bucle de entrenamiento¶

Este es el corazón de nuestro programa. Inicializaremos nuestros parámetros y luego ejecutaremos un bucle que los refinará repetidamente utilizando el Descenso del Gradiente.

Al tratarse de una muestra de datos muy pequeña con solo 50 elementos y para mantener el código sencillo, utilizaremos el descenso por lotes utilizando las 50 entradas en cada iteración.

Antes del bucle, escalamos la entrada. El número de pacientes va de 50 a 150, mientras que el sesgo se multiplica por un 1 constante. Con los valores sin escalar, el gradiente de $w$ es unas cien veces mayor que el de $b$: solo una tasa de aprendizaje diminuta mantiene estable $w$ y, con ella, $b$ apenas se mueve, así que el bucle se detiene mucho antes de llegar a la mejor recta. Como advierten las notas de Luis, el descenso del gradiente es sensible a la escala de las variables, y el remedio es normalizar los datos. Estandarizamos $x$ (le restamos su media y lo dividimos por su desviación típica), entrenamos con los valores escalados y al final devolvemos $w$ y $b$ a mascarillas por paciente.

Las actualizaciones usan los gradientes del error cuadrático medio, con el factor $2/m$ de las ecuaciones de actualización de Luis, donde $\alpha$ es la tasa de aprendizaje:

$$w := w - \alpha \, \frac{2}{m} \sum_{i=1}^{m} (\hat{y}_i - y_i)\, x_i \qquad b := b - \alpha \, \frac{2}{m} \sum_{i=1}^{m} (\hat{y}_i - y_i)$$

# Bloque de Código 3: Construyendo y Entrenando el Modelo (con Parada Temprana)

# --- 1. Escalado de la Característica ---
# El número de pacientes (de 50 a 150) es un número grande comparado con el 1
# constante que multiplica al sesgo. Lo estandarizamos: media 0 y desviación típica 1.
X_mean = X.mean()
X_std = X.std()
X_scaled = (X - X_mean) / X_std

# --- 2. Inicialización de Parámetros ---
# Necesitamos darle a nuestro modelo un punto de partida. Empecemos w y b en 0.
# Es una posición inicial simple y neutral.
w = 0.0
b = 0.0

# --- 3. Configuración de Hiperparámetros ---
# Estos son ajustes para el algoritmo de aprendizaje, no aprendidos de los datos.
# Tenemos que configurarlos nosotros mismos.
learning_rate = 0.01       # Cómo de grande es el paso en cada actualización (alfa en las notas de Luis).
num_iterations = 10000     # El número máximo de iteraciones.
tol = 0.001                # Tolerancia: cambio mínimo en el coste para seguir adelante (umbral de parada temprana).

# --- 4. El Bucle de Entrenamiento ---
# Almacenaremos el coste en cada paso para observar cómo aprende nuestro modelo.
cost_log = []

print("Iniciando la secuencia de entrenamiento...")
for i in range(num_iterations):
    # a) Realizar predicciones para TODOS nuestros puntos de datos con los w y b actuales.
    y_pred = w * X_scaled + b

    # b) Calcular el coste (MSE) para estas predicciones.
    # Esto nos dice cómo de bien lo estamos haciendo en esta iteración.
    cost = np.mean((y_pred - y)**2)
    cost_log.append(cost)

    # --- Condición de Parada Temprana ---
    # Si el coste no ha cambiado mucho en comparación con el paso anterior,
    # significa que hemos alcanzado una región plana, no estamos aprendiendo mucho más.
    if i > 0 and abs(cost_log[-2] - cost_log[-1]) < tol:
        print(f"Parada temprana en la iteración {i}: el coste apenas cambia.")
        break

    # c) Calcular los gradientes. Este es el núcleo del aprendizaje.
    # Estas fórmulas provienen de la derivada de la función de coste.
    # Nos dicen la pendiente de nuestra "colina" de coste para w y b.
    dw = (2/m) * np.sum((y_pred - y) * X_scaled)  # Gradiente para el peso
    db = (2/m) * np.sum(y_pred - y)               # Gradiente para el sesgo

    # d) Actualizar los parámetros.
    # Movemos w y b en la dirección *opuesta* a su gradiente.
    # Este es el paso "cuesta abajo".
    w = w - learning_rate * dw
    b = b - learning_rate * db

    # Un registro simple para seguir el proceso en tiempo real.
    # Imprimimos la evolución del error cada 100 iteraciones, empezando por la 1
    # (la iteración 0 es el punto de partida, w = b = 0).
    if ((i-1) % 100) == 0:
        print(f"Iteración {i}: Coste = {cost:.6f}")

# --- 5. De Vuelta a las Unidades Originales ---
# El modelo ha aprendido con los pacientes escalados. Deshacemos el escalado para que
# w sea "mascarillas por paciente" y b el número base de mascarillas.
b = b - w * X_mean / X_std
w = w / X_std

# imprimir el número de iteraciones y el error final
print("\n--- Entrenamiento Completo ---")
print(f"Número de iteraciones: {i}")
print(f"Error final: {cost:.6f}")
print(f"Peso aprendido final (w): {w:.4f}")
print(f"Sesgo aprendido final (b): {b:.4f}")

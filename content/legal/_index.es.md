## Política de Privacidad

### Recopilación de Datos

**Este sitio web NO recopila, almacena ni procesa directamente ningún dato personal de los visitantes.**

Específicamente, no:
- Usamos cookies para seguimiento o análisis
- Recopilamos direcciones de correo electrónico o información de contacto a través de formularios
- Usamos servicios de análisis de terceros (Google Analytics, etc.)
- Rastreamos el comportamiento del usuario o creamos perfiles de usuario
- Almacenamos ninguna información personal

### Alojamiento en GitHub Pages

Este sitio web está alojado en **GitHub Pages**, un servicio proporcionado por GitHub, Inc. Como proveedor de alojamiento, GitHub puede recopilar cierta información técnica como parte de sus operaciones estándar de servicio, incluyendo:

- Direcciones IP
- Tipo y versión del navegador
- Páginas de referencia/salida
- Fecha y hora de acceso
- Registros técnicos para el funcionamiento del servicio y seguridad

Esta recopilación de datos la realiza GitHub, no el propietario del sitio web. Para información sobre las prácticas de datos de GitHub, consulta:
- [Declaración de Privacidad de GitHub](https://docs.github.com/es/site-policy/privacy-policies/github-privacy-statement)
- [Documentación de GitHub Pages](https://docs.github.com/es/pages)
